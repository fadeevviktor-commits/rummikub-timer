# Руммикуб · Таймер для Android

**Установка 1.5:** APK подписан новым локальным ключом. Для перехода с версии 1.4 или более ранней сначала удалите старое приложение (сохранённые имена и текущая игра будут удалены), затем установите новый APK. Следующие сборки с этим ключом можно устанавливать поверх 1.5.

Нативное приложение на Java, Android 8.0 и новее, без сторонних библиотек и разрешения на Интернет.

## Возможности
- От 2 до 4 игроков, имена до 18 символов и 24 рисованных аватара: 12 животных, включая рыбку и барашка, и все 12 знаков зодиака.
- 30, 60, 90 или 120 секунд на ход.
- Порядок игроков меняется перетаскиванием за ручку ≡. Имя и аватар перемещаются вместе; первым начинает верхний игрок списка. Нажатие на ручку открывает выбор позиции — альтернатива перетаскиванию.
- Первый игрок нажимает «Старт». Следующее нажатие передаёт ход и запускает таймер следующего игрока.
- Сигнал нажатия, предупреждение на 10 секундах, короткие сигналы каждую последнюю секунду, сигнал истечения времени.
- При истечении времени звучит сигнал и автоматически запускается полный таймер следующего игрока. Завершить ход раньше можно нажатием большой кнопки.
- Игровой экран помещается в окно без прокрутки, с учётом системных панелей. Таймер меняет размер; в альбомной ориентации используется два столбца.
- Спокойный кремовый фон, синий акцент и рисованные аватары. На игровом экране — текущий игрок, крупное время, следующий игрок и пауза. Название исправлено на «Руммикуб».
- Игроки всегда расположены одним списком. Кнопка запуска закреплена внизу; на маленьких экранах список прокручивается. При открытой клавиатуре остаются редактор игроков и запуск.
- Нажатие на имя редактирует его, на аватар открывает выбор из вкладок «Животные» и «Зодиак».
- Звук, памятка и завершение игры доступны в меню ···. Открытие игрового меню ставит таймер на паузу; после закрытия нажмите «Продолжить».
- Пауза, отключение звука, сохранение настроек и текущей игры.
- При уходе приложения в фон таймер приостанавливается. После возвращения нужно нажать «Продолжить».
- Экран не гаснет во время игры. Звуки используют громкость мультимедиа Android.

## Сборка
Откройте папку проекта в Android Studio с JDK 17 или 21. Установите SDK Platform 35, дождитесь синхронизации Gradle и выберите Build → Build APK(s).
Если IDE предлагает выбрать Gradle, используйте 8.11.1. Gradle Wrapper в архив не включён: загрузить его в рабочей среде не удалось.
При установленном Gradle 8.11.1: `gradle :app:assembleDebug`.
Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Статус проверки
APK собран средствами Android SDK 35 и JDK 21. Подпись APK v2/v3 проверена. Тесты таймера проходят для 12 сочетаний количества игроков и времени, включая автоматическую передачу хода. Геометрия игрового экрана проверяется для 11 размеров окна, стартового — для 84 сочетаний размеров, числа игроков и наличия клавиатуры. Тесты перестановки проверяют вставку игрока во все допустимые позиции, сохранение связи имени с аватаром и относительного порядка остальных игроков.

Готовый файл: `rummikub-timer-v1.5.apk` (Android 8.0+). Версия 1.5 (versionCode 6), подписана новым ключом разработки.

Для повторной сборки без Gradle задайте JAVA_HOME, ANDROID_SDK_ROOT и при необходимости BUILD_TOOLS, затем запустите `./build-apk.sh`. Ключ хранится локально в `.local-signing/` и не включён в исходный архив.

На Windows с JDK 17/21 и Android SDK Platform 35 / Build Tools 35.0.0:

```powershell
powershell -ExecutionPolicy Bypass -File build-apk.ps1 -JavaHome 'C:\path\to\jdk' -SdkRoot 'C:\path\to\android-sdk'
```

Скрипт запускает тесты, собирает APK и проверяет подпись. Результат: `app/build/manual/apk/rummikub-timer-v1.5.apk`. Сохраните резервную копию `.local-signing/development.jks`: без него нельзя выпустить совместимое обновление.
